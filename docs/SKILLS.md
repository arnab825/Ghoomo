# Ghoomo - Engineering Skills & Guidelines

## Core Principles
1. **Map-First Always**: Never hide the map behind complex nested tabs where users lose spatial context.
2. **Deterministic Seed Magic**: For live hackathon demos, always provide pre-curated viral reel URLs with rich, authentic Indian photography so the judges see an instant jaw-dropping result.
3. **Traceability is Trust**: Never generate a place without linking back to the reel or video that inspired it.
