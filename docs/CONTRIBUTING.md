# Contributing to Ghoomo

## Development Workflow
1. Follow the domain structure (`auth`, `social-import`, `places`, `itinerary`, `map`, `collaboration`, `budget`, `checklist`, `trip-dashboard`).
2. Keep UI components presentational; keep business logic in feature modules and custom hooks.
3. Validate all inputs with Zod and TypeScript strict mode.
4. Ensure every feature is demo-ready, responsive, and adheres to dark mode glassmorphism guidelines.
